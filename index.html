Privacy by architecture

Your contact file cannot leave through the checker.

The checker has no backend, account, analytics or runtime data API. Its Content Security Policy sets connect-src 'none', which blocks fetch, XHR, WebSocket and beacon connections.

This marketing page counts its own visits with Vercel Web Analytics, which sets no cookie and reports only aggregate page views. That script never runs on the checker, so it cannot observe your CSV, contact count or matching decisions.

Questions

Before you use it

Does it merge records in HubSpot?

No. It keeps a selected row for each approved group in a new CSV; it does not combine fields. The full audit report preserves source values. Reimporting fewer rows does not delete or merge existing HubSpot contacts.

Will it remove possible matches automatically?

No. Every group stays intact until you approve it. You must confirm the final export separately.

What can it miss?

Contacts with no shared email, phone, surname or company signal may remain separate. Read the full limitations before using the output.

Is this a HubSpot product?

No. DedupeSafe is an independent tool and is not authorized, endorsed, sponsored or approved by HubSpot, Inc.
